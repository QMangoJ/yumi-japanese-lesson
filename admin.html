🌸 Yumi — Site Admin

Booking settings for yumi.ki-toko.com. Changes take effect immediately — no redeploy needed. This page only works with the admin key; without it, nothing here can read or change anything.

Admin key

Weekly hours (Japan time)

Lessons start on the hour. A lesson must end by the day's closing time. Untick a day to close it.

Blocked dates

Holidays and days off — no lessons can be booked on these dates. One date per line, as YYYY-MM-DD.

Online meeting

Shown in every booking confirmation and email. Leave empty and students will see “your teacher will send the meeting link before the lesson”.

Email (Resend)

Mail is sent as “Yumi Japanese Lessons <lesson-booking@yumi-japan.com>” via Resend.

Booking emails are always recorded in the outbox. They are actually sent only when both the From address and a Resend API key are set.
